### 1. 数据库字段扩展

| 值 | 含义 | GUI 显示 |
|----|------|----------|

### 2. 检测逻辑流程

```
开始检测
    │
    ▼
访问 one.google.com
    │
    ├── 检测到非 Pro 会员
    │       └── is_pro = "no"
    │
    └── 检测到 Pro 会员
            │
            ▼
        访问家庭组页面
        https://one.google.com/family
            │
            ├── 页面显示"您是家庭管理员"或"管理家庭群组"
            │       └── is_pro = "yes" (普通 Pro)
            │
            ├── 页面显示"您是家庭成员"或"退出家庭群组"
            │       └── is_pro = "family_yes" (家庭 Pro)
            │
            └── 无家庭组信息 / 页面提示创建家庭
                    └── is_pro = "yes" (普通 Pro)
```

## 修复记录

### 2026-02-03: 修复家庭组 Pro 误判问题

**问题描述**: 家庭组 Pro 被错误识别为普通 Pro

**根本原因**:
1. 检测顺序问题：先检查管理员标识，再检查成员标识
2. 关键词过于宽泛："家庭管理员"、"Family manager" 在成员页面也会出现（显示为"由 XXX（家庭管理员）管理"）

**修复方案**:
1. 颠倒检测顺序：先检测成员标识，再检测管理员标识
2. 优化关键词：
   - 移除 "家庭管理员"、"Family manager" 等模糊关键词
   - 移除 "您的 Google One 会员资格" 等通用关键词
   - 保留更精确的标识如 "管理家庭群组"、"邀请家庭成员" 等

**修改文件**: `automation/batch_account_processor.py`
