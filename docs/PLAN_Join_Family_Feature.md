## 实施阶段

### 阶段 1: 数据库扩展
**文件**: `services/database.py`

| 修改项 | 说明 |
|--------|------|
| 新增字段 | `family_member_count INTEGER DEFAULT 0` |
| 新增方法 | `update_family_member_count(email, count)` |
| 新增方法 | `get_available_pro_accounts()` - 返回 is_pro='yes' 且 family_member_count < 6 的账户 |

**字段说明**:
- `0` = 未检测/无家庭组
- `1-6` = 当前家庭成员数（包括管理员自己）
- 最大可邀请 = 6 - family_member_count

### 阶段 2: Pro 检测增强
**文件**: `automation/batch_account_processor.py`

| 修改项 | 说明 |
|--------|------|
| 修改方法 | `_check_google_one_pro_status()` |
| 新增逻辑 | 检测到普通 Pro 后，获取家庭成员数量 |
| 更新数据 | 调用 `update_family_member_count()` |

### 阶段 3: 自动化脚本 (核心)
**新建文件**: `automation/auto_join_family.py`

```python
@dataclass
class JoinFamilyResult:
    """加入家庭组结果"""
    success: bool
    message: str
    inviter_email: str
    invitee_email: str
    error_type: Optional[str] = None

async def auto_join_family(
    inviter_account: dict,      # 邀请人（普通 Pro）
    invitee_account: dict,      # 被邀请人（待加入的账户）
    callback: Callable = None,
) -> JoinFamilyResult:
    """
    完整的家庭组加入流程

    流程:
    1. 打开邀请人窗口，发送邀请
    2. 打开被邀请人窗口，接受邀请

    Returns:
        JoinFamilyResult: 包含 success, message, error_type
    """
```

**子函数**:
- `_send_family_invite()`: 在普通 Pro 窗口发送邀请
- `_accept_family_invite()`: 在被邀请人窗口接受邀请

**自动化流程详细设计**:

**Step A: 邀请流程 (在普通 Pro 窗口执行)**
1. 打开 https://myaccount.google.com/family
2. 检测当前家庭成员数量
3. 如果 >= 6，返回"已满"错误
4. 点击"邀请家庭成员"按钮
5. 输入被邀请人的 Gmail 地址
6. 点击"发送邀请"
7. 确认邀请已发送
8. 更新数据库中的 family_member_count

**Step B: 接受邀请流程 (在家庭组 Pro 窗口执行)**
1. 打开 https://mail.google.com
2. 搜索邀请邮件（关键词: "Google One family" 或 "加入家庭群组"）
3. 打开邮件
4. 点击"接受邀请"按钮/链接
5. 在跳转的 Google 页面确认加入
6. 更新被邀请账户的 is_pro 状态为 "family_yes"
