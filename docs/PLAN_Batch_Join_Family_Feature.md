## 功能概述

在账号管理窗口添加「一键加入家庭组」按钮，支持批量勾选普通账户，自动分配到可用的普通 Pro 账户家庭组中。

## Pro 账户状态说明

| Pro 状态 | 数据库值 | 说明 | 可加入家庭组 | 可邀请他人 |
|----------|----------|------|--------------|------------|
| **普通账户** | `no` 或 `unknown` | 没有任何 Pro 会员 | ✅ 可以 | ❌ |
| **普通 Pro** | `yes` | 自己订阅的 Pro | ❌ 不需要 | ✅ 可以（最多邀请5人） |
| **家庭组 Pro** | `family_yes` | 已通过家庭组获得 Pro | ❌ 已经是了 | ❌ |

## 分配算法

```python
def allocate_to_pro_accounts(invitees: List[dict], pro_accounts: List[dict]) -> List[tuple]:
    """
    将普通账户分配到 Pro 账户家庭组

    Args:
        invitees: 待加入的普通账户列表
        pro_accounts: 可用的 Pro 账户列表（已按 family_member_count 升序排序）

    Returns:
        List[(invitee, pro_account)] 分配结果
    """
    assignments = []
    pro_index = 0

    # 复制一份用于追踪当前容量
    pro_slots = {acc['email']: 6 - (acc.get('family_member_count') or 0) for acc in pro_accounts}

    for invitee in invitees:
        # 找到有空位的 Pro 账户
        while pro_index < len(pro_accounts):
            pro_email = pro_accounts[pro_index]['email']
            if pro_slots[pro_email] > 0:
                # 分配
                assignments.append((invitee, pro_accounts[pro_index]))
                pro_slots[pro_email] -= 1
                break
            else:
                # 当前 Pro 已满，切换下一个
                pro_index += 1
        else:
            # 所有 Pro 都满了
            break

    return assignments
```

## 用户交互流程

```
1. 用户勾选多个普通账户（is_pro = 'no' 或 'unknown'）
2. 点击「👨‍👩‍👧 一键加入家庭组」按钮
3. 系统检查：
   - 勾选的账户是否都是普通账户？
   - 是否都已登录且绑定窗口？
   - 是否有可用的 Pro 账户？
4. 显示确认对话框：
   ┌─────────────────────────────────────────────────┐
   │  即将分配 3 个普通账户到家庭组                    │
   │                                                 │
   │  可用 Pro 账户:                                 │
   │  • pro1@gmail.com (2/6) - 可邀请 4 人           │
   │  • pro2@gmail.com (5/6) - 可邀请 1 人           │
   │                                                 │
   │  分配预览:                                      │
   │  • user1 → pro1                                │
   │  • user2 → pro1                                │
   │  • user3 → pro1                                │
   │                                                 │
   │  ⚠️ 操作将串行执行，每个账户约需 1-2 分钟        │
   │                                                 │
   │           [取消]  [开始执行]                     │
   └─────────────────────────────────────────────────┘
5. 执行过程中显示进度日志
6. 完成后显示统计结果
```

## 错误处理

| 错误场景 | 处理方式 |
|----------|----------|
| 没有勾选账户 | 提示"请先勾选要加入家庭组的普通账户" |
| 勾选了非普通账户 | 自动过滤，只处理普通账户 |
| 没有可用 Pro 账户 | 提示"没有可用的普通 Pro 账户（需已登录、绑定窗口、家庭组未满）" |
| Pro 账户不足 | 提示"Pro 账户可用名额不足，仅能处理 X 个账户" |
| 单个账户加入失败 | 记录失败原因，继续处理下一个 |
| 账户未登录/未绑定窗口 | 跳过并计入 skipped_count |
